## First keep them in `/home/{user-name}/.local/bin/` directory

```bash
sudo mv  opencode-default-wifi  opencode-normal-wifi  opencode-flatpak-wifi
```

**Then**

```bash
chmod +x opencode-default-wifi  opencode-normal-wifi  opencode-flatpak-wifi
```

**Now you can able to use opencode in wifi mode though your whole pc priotize ethernet**

**Never forget to connect with wifi though you are already connected to ethernet**

**Here, `normal` mean normal app opencode , `default` mean default ai agent of Omarchy linux , `flatpak` mean flatpak version of opencode**
